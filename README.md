# Alpenglow

Local-first weekend planner for alpine trails. Pick a valley, a weather window,
and a fitness band — get a loop that fits Saturday, not a 14-hour ridge traverse.

This repo is a demo workspace. No accounts, no API keys, no real user data.

## Stack

- Next.js + React + TypeScript
- Pure functions for routing, weather windows, and difficulty scoring
- Seed data for public Swiss / Austrian hut-to-hut classics
